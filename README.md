# Major Moves Series

The Major Moves Series is the publishing engine for the Major AI Mindset ecosystem.

It turns visual manifestos into short e-books, workbooks, Substack essays, MAIM-site products, NotebookLM learning packs, podcasts, YouTube lessons, social assets, and community challenges.

## Core Principle

One visual seed can become a full doctrine, product, and learning system when the architecture is clear.

## Platform Roles

| Layer | Platform | Responsibility |
|---|---|---|
| Layer of Truth | GitHub | Version history, manuscripts, prompts, templates |
| Writing Room | Claude | Long-form drafting, expansion, refinement |
| Orchestration | ChatGPT | Strategy, systems architecture, curriculum, automation |
| Production | Airtable | Editorial pipeline and launch tracking |
| Knowledge | Notion | Research, reference, editorial library |
| Asset Vault | Google Drive | Covers, exports, audio, video, PDFs |
| Study + Audio | NotebookLM | Study guides, FAQs, audio discussions |
| Signal Layer | Substack | Audience validation and essays |
| Owned commerce | MAIM website + Stripe | Finished products, bundles, workbooks; fulfillment and entitlements must be verified before launch |

## Ecosystem alignment (2026-10-19)

Major Moves is the visual storytelling and publishing companion to the canonical 10 Pillars framework at `MajorDream444/MAIM_10_Pillars`, governed by `MajorDream444/Major-AI-OS`. The MAIM website is the only planned storefront; Gumroad, Shopify and Kit are retired. Visual stories, real-life founder narratives, five-minute actions, workbooks, quests, badges and optional collectibles are interconnected but distinct assets. The Ten Pillars companion app is proposed, not deployed. See `docs/MAIM_10_PILLARS_COMMERCE_APP_HANDOFF_2026-10-19.md`.
